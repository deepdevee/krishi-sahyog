# Google Stitch Design Exports

This directory preserves the 14 raw design screen mockups generated during the design sprint for KRISHI Sahyog.

Each folder contains:
- `code.html`: Raw HTML export of the individual screen design.
- `screen.png`: Visual design screenshot.

---
